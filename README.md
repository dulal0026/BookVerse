# BookVerse — Online Bookstore

A responsive frontend-only online bookstore, recreated from the BookVerse 1440px homepage design reference.

## Tech stack
- React 19 + Vite 6
- CSS (responsive layout and custom design tokens)
- Lucide React icons
- Static catalog data — no backend or database

## Features
- Responsive desktop, tablet, and mobile layout
- Search books by title, author, or category
- Browse category and bestseller tabs
- Add/remove items in a working demo cart
- Wishlist toggles and cart drawer
- BDT prices and discount presentation

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes
Book imagery is derived from the supplied generated UI reference. Checkout, authentication, and payments are not connected to any backend.
